# Code of Conduct

This project is for collaborative, technically precise learning.

Contributors are expected to:

- be respectful and constructive;
- distinguish facts, assumptions, and opinions;
- welcome corrections when technical claims are incomplete or wrong;
- avoid personal attacks, harassment, or exclusionary language;
- focus review comments on improving accuracy, clarity, and safety.

Maintainers may remove contributions or comments that undermine a productive technical environment.
